# GovnoLab — многостраничный сайт маркетингового агентства

Статический сайт на чистом HTML/CSS/JS без сборки и зависимостей. Демонстрационные данные.

## Страницы

| Файл | Что внутри |
|------|-----------|
| `index.html` | Главная: hero с графиком, анимированные счётчики, направления, избранные кейсы, отзывы |
| `services.html` | Услуги: 6 вкладок с составом работ и тарифами, интерактивный калькулятор окупаемости (ROMI) |
| `cases.html` | Кейсы: фильтр по отрасли, карточки открываются в модальном окне с метриками |
| `blog.html` | Блог: поиск и фильтр по рубрикам |
| `article.html?id=…` | Отдельная страница статьи, подгружается из данных |
| `about.html` | О нас: принципы, команда, FAQ-аккордеон, форма заявки с валидацией |

## Как запустить локально

Просто откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Как редактировать

- Кейсы и статьи — в `assets/js/data.js` (достаточно добавить объект в массив).
- Стили и цвета — в `assets/css/style.css` (переменные в `:root`).
- Общая логика (меню, табы, FAQ, форма, калькулятор) — в `assets/js/main.js`.

## Публикация на GitHub Pages

Settings → Pages → Source: «Deploy from a branch» → выбрать ветку и папку `/ (root)`. Сайт будет доступен по адресу `https://<username>.github.io/site1/`.
