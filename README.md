# GovnoLab — многостраничный сайт маркетингового агентства

Статический сайт на чистом HTML/CSS/JS без сборки и зависимостей. Демонстрационные данные.

## Страницы

| Файл | Что внутри |
|------|-----------|
| `index.html` | Главная: hero с графиком, анимированные счётчики, направления, избранные кейсы, отзывы |
| `services.html` | Услуги: 6 вкладок с составом работ и тарифами, интерактивный калькулятор окупаемости (ROMI) |
| `cases.html` | Кейсы: фильтр по отрасли, карточки открываются в модальном окне с метриками |
| `blog.html` | Блог: поиск и фильтр по рубрикам |
| `article.html?id=…` | Отдельная страница статьи, подгружается из данных |
| `about.html` | О нас: принципы, команда, FAQ-аккордеон, форма заявки с валидацией |

## Как запустить локально

Просто откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Языки (EN / RU)

Основной язык сайта — английский. Переключатель EN / RU в шапке справа, выбор запоминается в браузере.

- Английский текст живёт прямо в HTML и является источником истины.
- Русские переводы — в словаре `assets/js/i18n.js` (раздел `ru`). Элемент с атрибутом `data-i18n="ключ"` получает русский текст по этому ключу; для атрибутов есть `data-i18n-placeholder`, `data-i18n-content`, `data-i18n-aria-label`.
- Кейсы и статьи в `assets/js/data.js` хранят оба языка в полях вида `{ en: "...", ru: "..." }`.
- Чтобы добавить новый текст: напишите его по-английски в HTML, добавьте `data-i18n="новый.ключ"` и строку `"новый.ключ": "Русский текст"` в раздел `ru` словаря.
- Чтобы поправить русский перевод: найдите ключ в `assets/js/i18n.js` (раздел `ru`) и измените строку.

## Оформление

Тёмная тема. Все цвета, радиусы и тени заданы переменными в начале `assets/css/style.css` (блок `:root`): чтобы поменять акцентный цвет или фон, достаточно изменить одну строку там.

Шрифт Inter подключён с Google Fonts; если он недоступен, используется системный.

Ссылки на CSS и JS в HTML имеют суффикс `?v=N`. После правок в `style.css` или скриптах увеличьте число во всех шести страницах (поиск и замена `?v=9` → `?v=10`), чтобы браузеры и GitHub Pages не показывали старую версию из кэша.

## Анимированный фон

За контентом медленно дрейфуют бледные слова и аббревиатуры (SEO, AI, GitHub, Claude…). Каждое слово — элемент `<span>` с CSS-анимацией (`.bd-word` в `style.css`), поэтому при прокрутке они двигаются вместе со страницей без рывков. Скрипт `assets/js/backdrop.js` создаёт слова и переставляет их после каждого цикла растворения; список слов, яркость (`MAX_ALPHA`), скорость (`SPEED`) и плотность (`DENSITY`) задаются константами в начале файла. При системной настройке «уменьшить движение» слова показываются статично.

## Иконки

Иконки — набор [Lucide](https://lucide.dev/icons) (открытая лицензия ISC), встроены как SVG в `assets/js/icons.js`. Используются в карточках услуг, статистике, обложках кейсов, фильтрах, рубриках блога, FAQ, контактах, кнопках и ссылках.

- В HTML: `<span data-icon="target"></span>` — имя иконки из списка в `icons.js`.
- В JS: `ICONS.svg("target")`.
- Иконки кейсов задаются полем `icon` в `assets/js/data.js`.
- Чтобы сменить набор, замените SVG-контуры в `icons.js`, сохранив имена; HTML трогать не нужно.

## Валюта

В английской версии цены в долларах, в русской — в рублях. Где править:

- Тарифы: английские значения прямо в `services.html`, русские — в словаре `assets/js/i18n.js`.
- Калькулятор: диапазоны ползунков и формат валюты для каждого языка — объект `CFG` в `assets/js/main.js`.
- Счётчики на главной: атрибуты `data-prefix`, `data-suffix` (EN) и `data-*-ru` (RU) в `index.html`.
- Метрики кейсов: поле `value` в `assets/js/data.js` может быть строкой или объектом `{ en, ru }`.

## Как редактировать

- Кейсы и статьи — в `assets/js/data.js` (достаточно добавить объект в массив, оба языка).
- Стили и цвета — в `assets/css/style.css` (переменные в `:root`).
- Общая логика (меню, табы, FAQ, форма, калькулятор) — в `assets/js/main.js`.
- Переводы и переключатель языка — в `assets/js/i18n.js`.

Settings → Pages → Source: «Deploy from a branch» → выбрать ветку и папку `/ (root)`. Сайт будет доступен по адресу `https://<username>.github.io/site1/`.
